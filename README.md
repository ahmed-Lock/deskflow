# DeskFlow

A lightweight desktop workflow dashboard.

The original idea was to have one place for tasks, notes
and small utilities that we were using during university
projects.

## Features

- Task tracking
- Notes
- Simple dashboard
- Local authentication
- Export/import

## Requirements

- Python 3.x

## Installation

```bash
pip install -r requirements.txt

Running
python3 backend/app.py

Then open the local dashboard in a browser.

Project structure

The backend contains the small API and application logic.

The frontend contains the dashboard interface.

Additional documentation can be found in the docs
directory.

Status

The project is no longer actively developed.

It was mainly built as a university learning project and
was useful for experimenting with different parts of a
small web application.
